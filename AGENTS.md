# Project rules

## Changelog categories

Use `Startup`, `Episodes`, `Library`, `Diagnostics`, `Authentication`, `Models`, `Branding`, `Dependencies`, `Security`, and `Memory` for changes to local setup, video ingestion, the saved video list, error recording, sign-in or sign-up, model settings, the product name, package updates, data protection, and Fuzzy Brain sync.
Add a new category only when a change does not fit one of these areas.
