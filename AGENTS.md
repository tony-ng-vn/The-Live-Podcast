# Project rules

## Changelog categories

Use `Startup`, `Episodes`, `Library`, `Diagnostics`, `Authentication`, `Models`, `Branding`, `Dependencies`, and `Security` for changes to local setup, video ingestion, the saved video list, error recording, sign-in or sign-up, model settings, the product name, package updates, and data protection.
Add a new category only when a change does not fit one of these areas.
